Canvas Deadline Helper

A simple Chrome extension that helps Babson students see upcoming assignment deadlines on Canvas.

What It Does

Deadline Detection

Reads assignment names and due dates directly from supported Canvas assignment pages.

Highlighting

Highlights assignments that are due within the next seven days, so they are easy to spot.

Popup List

Shows all detected upcoming assignments in a popup window, sorted by deadline.

How To Install

  1. Go to the GitHub repository and click the green Code button, then choose Download ZIP.
  2. Unzip the downloaded file on your computer.
  3. Open Chrome and go to chrome://extensions.
  4. Turn on Developer mode using the toggle in the top right corner.
  5. Click Load unpacked.
  6. Select the unzipped folder that contains the manifest.json file.

How To Use It

This extension works on supported Babson Canvas course Assignments pages. You must be logged into Canvas for the extension to detect assignments and due dates. Open an Assignments page for one of your courses, then click the extension icon to see your upcoming deadlines in the popup.

Note: This extension only reads information already shown on the page. It never modifies or submits any Canvas assignments.
